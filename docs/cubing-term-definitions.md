| Term | Definition |
|------|------------|
| Trigger | A short sequence of moves able to be performed fast. They generally 3 or 4 moves. Typically, a trigger is an R or L move, followed by a U move (U, U' or U2), and ending with the reverse of first move. For example R U R'. |
| AUF | Adjust U face. Means a U move (U, U', or U2) was applied to the start or end of an alg. |
| Rotation | Any x y or z move. For example, z2. Larger suffixes like x3, y3', etc. are not valid. |
| Move | Any turn of the face or faces of the cube, including full cube rotations (x, y, z). |
| Angle | The direction the cube is viewed at by the cuber. Changing the viewing angle fundamentally changes the "location" of a piece. x y and z moves change the angle of the cube. Sometimes, angle refers to a combination of a rotation and an AUF applied to a cube. |
| LL | Last layer. The layer solved after F2L, on the U face. |
| EO | Edge orientation. Solved for the LL when all four LL edges have their LL-color sticker facing up. |
| CO | Corner orientation. Solved for the LL when all four LL corners have their LL-color sticker facing up. |
| EP | Edge permutation. Solved when the LL edges sit in the right places relative to the rest of the cube. A pending AUF does not make it unsolved. |
| CP | Corner permutation. Solved when the LL corners sit in the right places relative to the rest of the cube. A pending AUF does not make it unsolved. |
| OLL | Orienting the last layer: EO and CO together. Also the name of the case set for that step. |
| PLL | Permuting the last layer: EP and CP together. Also the name of the case set for that step. |
| ZBLL | A last layer case that starts from EO solved and CO not solved, and ends solved or one AUF away. CP and/or EP may already be solved at the start and it is still a valid ZBLL case. A state with EO solved has both an OLL name and a ZBLL name, and both are meaningful — which one describes a given line depends on how much of the LL that line solves. |
| ZBLS | ZB (the inventer's initials) Last Slot. Solving the final F2L pair while also solving EO, so the solve continues into ZBLL. It is the *last* slot: the other three slots are solved, and EO is solved everywhere except possibly the slot being solved into. |
| F2L+EO | Not a standard set name. An alg that solves a pair and EO but is not ZBLS because it modifies multiple slots. |
| Substep order | Any LL substep (EO, CO, EP, CP) can be solved before any other, and a substep can be undone by later moves. Assume nothing about ordering. The most typical solver does OLL then PLL, but CP and/or EP may already be solved beforehand and simply be ignored by the solver, who then solves EO and CO as normal. |
